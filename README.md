# Consisav — Sitio web (rediseño)

Estructura del proyecto:

```
consisav-web/
├── index.html        Página principal
├── css/
│   └── style.css     Todos los estilos del sitio
├── js/
│   └── script.js      Interactividad (menú, círculos de servicios, scroll-spy)
├── images/
│   └── consisav-logo.png
└── README.md
```

## Cómo usarlo

1. Descomprimí el ZIP manteniendo esta misma estructura de carpetas
   (no muevas ni renombres `css/`, `js/` o `images/`).
2. Abrí `index.html` con cualquier navegador para verlo localmente.
3. Para publicarlo (GitHub Pages, hosting, etc.), subí la carpeta
   completa tal cual — `index.html` ya referencia los archivos con
   rutas relativas (`css/style.css`, `js/script.js`,
   `images/consisav-logo.png`).

## Edición

- **Textos y estructura:** `index.html`
- **Colores, tipografía, layout:** `css/style.css`
- **Menú, panel de servicios interactivo, scroll-spy:** `js/script.js`
